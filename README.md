# Guard for CC · Claude 保护

**版本：v10.8**（控制台 7.7 · 守护 7.6 · 内置内核 mihomo v1.19.32）

让 Claude（桌面版 / Claude Code / 网页）只能经过你锁定的**一个**代理节点上网，节点不通就断网，绝不回落到真实网络。适用于 Windows 10 / 11（64 位）。

## 功能

- **零回落**：开启保护后防火墙默认拒绝所有出站，只放行代理内核；只用锁定的单个节点，没有直连兜底。
- **守护进程**：每 2 秒体检（内核、TUN、路由、防火墙、DNS），定时检查出口 IP 和国家，异常立即拦截 Claude。
- **出口变化提醒**：出口 IP 与上次不一致时标红提醒。
- **两种引擎，可热切换**：
  - 内置引擎：自带 mihomo 内核，不需要装别的软件，换节点约 1 秒；
  - Clash Verge：使用本机的 Clash Verge，自动套用严格配置、关闭保护时还原。
- **节点来源**：白羊加速订阅，或导入自己的 Clash / mihomo 配置文件（只取其中的节点）。
- **控制台**：概览、节点与引擎、流量统计、连接、规则、日志、Claude 进程、维护（更新 / 回退 / 修复），托盘常驻，多种主题。
- **应急恢复**：一键恢复默认网络。

## 使用

1. 下载后把整个文件夹放到固定位置；
2. 双击 `1-安装或更新.bat`（需要管理员）；只安装程序，不会自动开启保护；
3. 控制台 →「节点与引擎」：选节点（没有白羊订阅就先「导入本地配置」）；
4. 「概览」→「开启保护」，状态变成「保护中」即可使用 Claude。

出问题：`2-应急恢复网络.bat`；卸载：`3-卸载.bat`。详细说明见 `使用说明.txt`。

## 说明

- 内置内核 `Config_Template/core/cg-mihomo.exe` 为 [mihomo](https://github.com/MetaCubeX/mihomo) 官方构建（GPL-3.0），见 `第三方软件说明.txt`。
- 保护开启时，除局域网、少数国内开发镜像和腾讯云控制台外，电脑上所有流量都走锁定节点。
- 本工具只控制本机网络出口，不保证任何服务的账号安全，风险自负。
